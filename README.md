## 🌍 English

**Kitap Atlası** (Book Atlas) is a full-featured web platform built with **.NET** that seamlessly integrates a classic library management system with a modern e-book reading experience. Whether you're managing a physical book inventory or offering digital reading, Kitap Atlası provides all the tools you need in one place.

### ✨ Features

| Category | Features |
|---|---|
| 📚 **Book Management** | Add, edit, and delete books from the catalog |
| ✍️ **Author Management** | Add, edit, and delete author profiles |
| 📖 **E-Book Reader** | Read digital books directly in the browser |
| 📅 **Events & Fairs** | Stay up-to-date with book fairs and literary events |
| 🔐 **User Accounts** | Secure login and registration system |
| 🔄 **Borrowing System** | Track book loans and returns with ease |

## 🇹🇷 Türkçe

**Kitap Atlası**, klasik kütüphane yönetimini modern e-kitap okuma deneyimiyle bir araya getiren **.NET** tabanlı kapsamlı bir web platformudur. Fiziksel kitap envanterini yönetmek ya da dijital okuma imkânı sunmak isteyenler için ihtiyaç duyulan tüm araçları tek çatı altında toplar.

### ✨ Özellikler

| Kategori | Açıklama |
|---|---|
| 📚 **Kitap Yönetimi** | Katalogdaki kitapları ekle, düzenle ve sil |
| ✍️ **Yazar Yönetimi** | Yazar profillerini ekle, düzenle ve sil |
| 📖 **E-Kitap Okuyucu** | Dijital kitapları doğrudan tarayıcıda oku |
| 📅 **Etkinlik Takvimi** | Kitap fuarları ve edebi etkinlikleri takip et |
| 🔐 **Kullanıcı Hesapları** | Güvenli giriş ve kayıt sistemi |
| 🔄 **Ödünç Takibi** | Kitap ödünç alma ve iade işlemlerini kolayca yönet |
